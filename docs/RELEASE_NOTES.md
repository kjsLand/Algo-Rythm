Algo-Rythm generates guitar song starters: key, tempo, form, chords, voicings, strums and an optional melody hook.

## Downloads

- **macOS:** `Algo-Rythm-<version>-macOS.dmg` (universal: Apple silicon and Intel). It also has `algo-cli`.
- **Windows:** `Algo-Rythm-<version>-Windows.zip`. It has `Algo-Rythm.exe` and `algo-cli.exe`.

## Limits of this build

These builds are not signed. The project has no Apple Developer ID and no Windows code signing certificate yet.

- On macOS, Gatekeeper blocks the first start. Right-click `Algo-Rythm.app`, select **Open**, then select **Open** again.
- On Windows, SmartScreen can show a warning. Select **More info**, then **Run anyway**.

docs/RELEASE.md tells you how to make signed and notarized builds.
